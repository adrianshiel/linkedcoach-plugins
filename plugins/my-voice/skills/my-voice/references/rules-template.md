# My Voice Rules template

This is the shape of every user's Rules doc. voice-setup builds the first version from it, and voice-review keeps to it. Use only headings, bullets, plain paragraphs and bold (see drive.md).

Each rule is one bullet, written as an instruction with a short example where an example helps. Don't record a rule's history. Add a reason only when it stops a known mistake recurring.

Leave out any section the user has nothing for, except Registers, Everywhere and Default rules switched off, which are always there. "Default rules switched off" is always the last section, because it shows a read got the whole doc.

Stay under 27,000 characters, and use no emoji characters: describe them in words (see drive.md). Don't repeat a default rule unless the user's version adds something, such as their own example or an exception.

## How this works

Claude reads this document before writing anything for you. When you correct something Claude wrote, it's logged in My Voice Corrections Log, and each week Claude reviews the log with you and proposes changes here. Nothing changes without your yes. You can also edit this document yourself at any time.

## Registers

A register is Established when it rests on real samples or several approved corrections, Thin when it has only a few rules, and Not established when it has none yet.

## Everywhere
